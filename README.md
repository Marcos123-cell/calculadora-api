# Calculadora API

API REST desenvolvida com Java e Spring Boot para praticar conceitos fundamentais de desenvolvimento back-end.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão

## Tecnologias

- Java 21
- Spring Boot
- Maven
- Lombok
- Postman

## Conceitos praticados

- Controllers
- Services
- DTOs
- Enums
- Path Variables
- Tratamento de exceções
- Arquitetura em camadas

## Endpoints

GET /calcular/somar/{n1}/{n2}

GET /calcular/subtrair/{n1}/{n2}

GET /calcular/multiplicar/{n1}/{n2}

GET /calcular/dividir/{n1}/{n2}
